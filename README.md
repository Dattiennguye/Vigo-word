# VIGO: Empire & Civilization

Game mô phỏng xây dựng quốc gia, quản lý thành phố, kinh tế, công nghệ, quân đội, ngoại giao và chiến tranh. Chơi hoàn toàn offline, các quốc gia còn lại do AI điều khiển.
